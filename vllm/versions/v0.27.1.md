# vLLM v0.27.1 Source Audit

Release: 2026-08-11  
Upstream: https://github.com/vllm-project/vllm/releases/tag/v0.27.1

## 1. Executive assessment

v0.27.1은 v0.27.0 위의 단일 기능 patch다.

- quantized DSpark Markov head support: #50424

일반 serving에는 작은 patch지만, DSpark를 사용하는 DeepSeek/Kimi/Qwen 계열에서는 compatibility significance가 높다.

## 2. Why it matters

Speculative decoding checkpoint가 quantized target과 별개로 draft/Markov head quantization을 포함할 수 있다.

따라서 `target model loads`만으로 DSpark compatibility를 판단하면 안 된다.

검증 항목:

- target weight format
- draft/Markov head weight format
- draft model config parser
- load-time quantization scheme
- draft logits correctness
- acceptance rate
- scheduled token budget
- CUDA Graph capture/replay

## 3. Platform action

DSpark를 평가하는 경우 v0.27.0 대신 0.27.1을 0.27 branch의 practical baseline으로 취급한다.
