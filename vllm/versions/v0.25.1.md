# vLLM v0.25.1 Source Audit

Release: 2026-07-14  
Upstream: https://github.com/vllm-project/vllm/releases/tag/v0.25.1

## 1. Executive assessment

v0.25.1은 v0.25.0 위의 2-commit patch지만, 하나는 serving startup, 다른 하나는 **silent output corruption**을 막는 수정이어서 historical audit에서 제외하면 안 된다.

## 2. TorchCodec startup guard

PR #47888은 system FFmpeg가 없는 환경에서 `import torchcodec`가 startup 단계에서 `RuntimeError`를 던져, TorchCodec를 실제 사용하지 않는 모델도 `vllm serve`가 막히는 문제를 수정했다.

Air-gapped/minimal image에서 중요하다.

Platform implication:

- optional multimedia dependency는 import-time hard dependency가 되어서는 안 된다.
- custom image slimming 시 model startup smoke test를 text-only / multimodal로 나눠야 한다.
- Python frontend/import graph가 runtime dependency policy에 영향을 준다.

## 3. FlashInfer all-reduce + RMSNorm fusion correctness

PR #48330은 fused FlashInfer all-reduce + RMSNorm + static quantization pattern에 dtype guard를 추가했다.

문제 조건 예:

- activation/residual: BF16
- RMSNorm weight: FP32
- NVFP4 등 quantized model

잘못된 fusion이 match되면 hidden state가 손상되어 반복 `!!!!!` 같은 garbage output이 발생할 수 있었다.

이 patch가 중요한 이유는 이후 v0.29에서 FlashInfer all-reduce가 TP CUDA group의 default path로 더 넓어지기 때문이다.

따라서 migration validation에서 단순 throughput만 보면 안 되고:

- deterministic prompt corpus
- greedy decode token IDs
- long decode
- TP size별 결과
- quantized/unquantized
- RMSNorm dtype

을 같이 비교해야 한다.

## 4. Platform action

0.25.0과 0.25.1 사이의 차이는 feature가 아니라 safety fix다. 과거 regression을 bisect할 때 0.25.0을 기준으로 잡기보다 0.25.1을 `0.25 stable`에 가깝게 취급한다.
